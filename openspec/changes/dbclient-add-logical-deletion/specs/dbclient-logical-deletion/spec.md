# dbclient-logical-deletion Specification

## Purpose

为数据库客户端（dbclient）提供逻辑删除能力：标注逻辑删除字段的实体可通过逻辑删除替代物理删除，常规查询自动排除已删除记录，并支持将已删除记录恢复为正常状态，从而满足需要保留数据痕迹的使用场景。

## ADDED Requirements

### Requirement: 实体逻辑删除字段标注

实体类可以通过字段注解将一个字段声明为逻辑删除字段，用于记录删除状态。注解 MUST 支持配置“已删除值”与“未删除值”，默认分别为 1 与 0，并适用于数值与布尔类型的字段。同一实体 MUST 最多只有一个逻辑删除字段。

#### Scenario: 使用默认值标注

- **WHEN** 实体字段被标注为逻辑删除字段且未配置任何取值
- **THEN** 该字段的未删除值为 0、已删除值为 1

#### Scenario: 自定义删除值与未删除值

- **WHEN** 标注时配置已删除值为 2、未删除值为 1
- **THEN** 后续逻辑删除操作将字段写为 2，恢复操作将字段写回 1，且常规查询按"不等于 2"排除已删除记录

#### Scenario: 布尔类型字段

- **WHEN** 布尔类型字段被标注为逻辑删除字段
- **THEN** 逻辑删除将其写为"已删除值"对应的布尔值（默认 true），恢复将其写回"未删除值"对应的布尔值（默认 false）

#### Scenario: 同一实体标注多个逻辑删除字段

- **WHEN** 同一实体标注了多个逻辑删除字段并执行逻辑删除、恢复或显式查询已删除记录的操作
- **THEN** 操作失败并给出明确的异常提示，且不执行任何 SQL

### Requirement: 新增逻辑删除操作

系统 MUST 提供按主键 ID、按条件以及 Lambda 构建器入口的逻辑删除方法，将目标记录的逻辑删除字段更新为“已删除值”，并返回受影响行数。逻辑删除 MUST NOT 物理删除任何数据。当实体未标注逻辑删除字段、或按 ID 操作传入 null 时，操作 MUST 失败并给出明确的异常提示，且不执行任何 SQL。

#### Scenario: 按 ID 逻辑删除

- **WHEN** 对标注实体按主键 ID 执行逻辑删除
- **THEN** 对应记录未被物理删除，其逻辑删除字段被更新为"已删除值"，方法返回受影响行数

#### Scenario: 按条件逻辑删除

- **WHEN** 通过条件构建器对标注实体执行逻辑删除
- **THEN** 仅满足条件的记录被更新为"已删除值"，不满足条件的记录不受影响

#### Scenario: 对已删除记录重复逻辑删除

- **WHEN** 对已处于删除状态的记录再次执行逻辑删除
- **THEN** 记录数据保持不变，重复执行不产生额外数据影响

#### Scenario: 未标注实体执行逻辑删除

- **WHEN** 对未标注逻辑删除字段的实体执行逻辑删除
- **THEN** 操作失败并给出明确的异常提示，且不执行任何 SQL

#### Scenario: 按 ID 逻辑删除传入 null

- **WHEN** 按 ID 逻辑删除时传入 null
- **THEN** 操作失败并给出明确的异常提示，且不执行任何 SQL

### Requirement: 既有物理删除 API 行为保持不变

既有删除 API（按 ID 删除、按条件删除、Lambda 删除构建器）MUST 保持物理删除语义，即使实体已标注逻辑删除字段也不例外。未标注实体的全部既有行为 MUST 保持不变。

#### Scenario: 对标注实体调用既有删除方法

- **WHEN** 对标注了逻辑删除字段的实体调用既有按 ID 删除或按条件删除方法
- **THEN** 目标记录被物理删除，行为与本次变更前完全一致

#### Scenario: 对未标注实体调用既有删除方法

- **WHEN** 对未标注逻辑删除字段的实体调用既有删除方法
- **THEN** 行为与本次变更前完全一致

### Requirement: 常规查询自动排除已删除记录

对标注逻辑删除字段的实体，全部常规查询入口（按 ID 单条查询、单条查询、列表查询、按实体/Map 条件查询、分页查询（含总数统计）、COUNT 统计、流式查询、单列查询）MUST 自动追加“不等于已删除值”的过滤条件，MUST NOT 返回已删除记录。对未标注逻辑删除字段的实体，全部查询行为 MUST 与本次变更前完全一致。

#### Scenario: 列表与条件查询排除已删除记录

- **WHEN** 对标注实体执行列表查询或按实体/Map 条件查询
- **THEN** 结果中不包含逻辑删除字段等于"已删除值"的记录，其他记录不受影响

#### Scenario: 按 ID 与单条查询排除已删除记录

- **WHEN** 对标注实体按 ID 或按条件查询单条记录，且目标记录已被逻辑删除
- **THEN** 查询结果为 null（不返回该记录）

#### Scenario: 分页与统计口径一致

- **WHEN** 对包含已删除记录的数据集执行分页查询（含总数统计）或 COUNT 统计
- **THEN** 返回的记录列表与总数均不包含已删除记录，两者口径一致

#### Scenario: 流式与单列查询排除已删除记录

- **WHEN** 对标注实体执行流式查询或单列查询
- **THEN** 结果流与列值列表中均不包含来自已删除记录的数据

#### Scenario: 未标注实体的查询行为不变

- **WHEN** 对未标注逻辑删除字段的实体执行任意常规查询
- **THEN** 行为与本次变更前完全一致

### Requirement: 显式查询包含已删除记录

系统 MUST 提供显式入口，用于对标注实体执行“包含已删除记录”的查询；该入口返回的结果集同时包含未删除与已删除记录，分页场景下总数统计与记录口径一致。对未标注逻辑删除字段的实体使用该入口时 MUST 失败并给出明确的异常提示。

#### Scenario: 显式查询包含已删除记录

- **WHEN** 对标注实体通过显式入口执行查询
- **THEN** 结果同时包含未删除记录与已删除记录

#### Scenario: 显式查询的分页口径一致

- **WHEN** 对标注实体通过显式入口执行分页查询
- **THEN** 记录列表与总数统计均包含已删除记录，两者口径一致

#### Scenario: 未使用显式入口的常规查询

- **WHEN** 对标注实体执行常规查询（未使用显式入口）
- **THEN** 结果不包含已删除记录

#### Scenario: 未标注实体使用显式入口

- **WHEN** 对未标注逻辑删除字段的实体使用显式入口查询
- **THEN** 操作失败并给出明确的异常提示，且不执行任何 SQL

### Requirement: 恢复已删除记录

系统 MUST 提供按主键 ID 与按条件的恢复方法，将已删除记录的逻辑删除字段写回“未删除值”，并返回受影响行数；恢复后该记录重新对常规查询可见。对未处于删除状态的记录执行恢复 MUST NOT 改变其数据。当实体未标注逻辑删除字段、或按 ID 恢复传入 null 时，操作 MUST 失败并给出明确的异常提示，且不执行任何 SQL。

#### Scenario: 按 ID 恢复

- **WHEN** 对已逻辑删除的记录按主键 ID 执行恢复
- **THEN** 该记录的逻辑删除字段被写回"未删除值"，且该记录重新出现在常规查询结果中

#### Scenario: 按条件恢复

- **WHEN** 通过条件构建器对已逻辑删除的记录执行恢复
- **THEN** 仅满足条件的记录被写回"未删除值"，不满足条件的记录不受影响

#### Scenario: 恢复未处于删除状态的记录

- **WHEN** 对未处于删除状态的记录执行恢复
- **THEN** 记录数据保持不变

#### Scenario: 未标注实体执行恢复

- **WHEN** 对未标注逻辑删除字段的实体执行恢复
- **THEN** 操作失败并给出明确的异常提示，且不执行任何 SQL

#### Scenario: 按 ID 恢复传入 null

- **WHEN** 按 ID 恢复时传入 null
- **THEN** 操作失败并给出明确的异常提示，且不执行任何 SQL
