# dbclient-logical-deletion Specification

## ADDED Requirements

### Requirement: 客户端条件构建器支持逻辑删除与恢复转换

系统 MUST 支持将客户端条件构建器转换为逻辑删除操作与恢复操作，转换后可直接执行。转换 MUST 完整保留该条件构建器此前构建的全部条件；执行 MUST 遵循既有逻辑删除/恢复语义：将逻辑删除字段更新为"已删除值"（逻辑删除）或写回"未删除值"（恢复），并返回受影响行数。当实体未标注逻辑删除字段、标注了多个逻辑删除字段或取值非法时，转换 MUST 失败并给出明确的异常提示，且不执行任何 SQL。

#### Scenario: 条件构建器转换为逻辑删除

- **WHEN** 通过客户端条件构建器构建了多个条件后，将其转换为逻辑删除操作并执行
- **THEN** 仅满足全部已构建条件的记录的逻辑删除字段被更新为"已删除值"，其他记录不受影响，操作返回受影响行数

#### Scenario: 条件构建器转换为恢复

- **WHEN** 通过客户端条件构建器构建了多个条件后，将其转换为恢复操作并执行
- **THEN** 仅满足全部已构建条件的已删除记录的逻辑删除字段被写回"未删除值"，恢复后重新对常规查询可见，操作返回受影响行数

#### Scenario: 未标注实体转换失败

- **WHEN** 对未标注逻辑删除字段的实体，通过客户端条件构建器转换为逻辑删除或恢复操作
- **THEN** 操作失败并给出明确的异常提示，且不执行任何 SQL
